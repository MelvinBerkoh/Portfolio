# Melvin Berkoh — Portfolio

My personal software engineering portfolio.

**Live site:** [melvinberkoh.com](https://melvinberkoh.com)

## About

This site highlights the projects, case studies, and engineering work I have built across full-stack development, frontend systems, data, and AI-assisted software.

Featured work includes:

- **OpsDesk** — multi-tenant support operations platform
- **Application Tracker** — full-stack job search workspace
- **PolicyScope** — AI-assisted Chrome extension for policy scanning
- **CommercePulse** — e-commerce analytics pipeline and dashboards

## Built With

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Motion
- Lucide React
- Vercel

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

For a production check:

```bash
npm run lint
npm run build
```

## Project Structure

```text
src/app/                     App Router pages, metadata, sitemap, and SEO
src/components/home/         Main portfolio sections and interactions
src/data/                    Site and project content
public/                      Resume and static assets
```
